# HourStudy 📚

**HourStudy** is a web-based study platform landing page designed to provide students with an organized and engaging online learning experience.

## 🌐 Live Demo

[Visit HourStudy](https://Ritesh7367.github.io/Hourstudy/)

## 📖 About the Project

HourStudy is a frontend web project built to present a study-focused platform through a clean and user-friendly interface. It demonstrates the use of HTML, CSS, and JavaScript to build an interactive website.

## ✨ Features

- Study-focused landing page
- Clean and user-friendly interface
- Blog page for learning-related content
- Interactive elements using JavaScript
- Responsive layout, if implemented

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ritesh7367/Hourstudy.git
   ```

2. Open the downloaded folder in VS Code.
3. Open `index.html` in your browser.
